# Decisions

One entry per decision, newest first: what was decided, when, by whom and why. Write the entry when the decision is made. An agent drafts an entry only when asked, and the person who decided confirms its wording.

## Decisions

### YYYY-MM-DD: the decision in one line

- **Decided by:** name
- **Why:** the reason, with links to the issue, pull request or note
- **Instead of:** the alternatives considered
